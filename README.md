# Pantry Pal

A recipe keeper app that tells you what you can — and can't — cook, based on
what's actually in your pantry. Store the recipes you want to hold onto,
keep a running list of what's in your kitchen, and skip the guesswork:
Pantry Pal checks each recipe's ingredients against your pantry so you're
never left wondering what to make.

## Tech stack

- **Next.js** — both the frontend and backend, using the App Router
- **React** and **TypeScript** — the frontend
- **Supabase (Postgres)** — the database
- **Vercel** — deployment
